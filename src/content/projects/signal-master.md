Грантовый проект, победивший в федеральной программе «Студенческий стартап». Signal-Master — аппаратно-программный комплекс, который унифицирует удалённое управление измерительным оборудованием.

## Стек

- **FastAPI** — backend и REST API для управления оборудованием
- **PyVISA** — взаимодействие с измерительными приборами по протоколу VISA
- **Raspberry Pi 5** — аппаратная платформа
- **Bash** — сценарии Wi-Fi fallback для восстановления связи при потере сети

## Роль

Руководитель проекта: постановка технических задач, архитектура системы, взаимодействие с грантовым фондом.
